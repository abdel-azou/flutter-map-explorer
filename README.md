# Mural Map

Application Flutter pour découvrir les fresques du parcours BD de Bruxelles, en liste ou sur une carte.

Réalisée dans le cadre du cours de développement mobile, Haute École Léonard de Vinci, 2025-2026.

## Fonctionnalités

- Liste des fresques issue des [données ouvertes de la Ville de Bruxelles](https://opendata.brussels.be)
- Carte OpenStreetMap et mini-carte sur chaque fiche
- Localisation de l'utilisateur et distance jusqu'à la fresque
- Navigation avec `go_router`

## Lancer le projet

```bash
flutter pub get
flutter run
```

La localisation demande l'autorisation de l'appareil.
